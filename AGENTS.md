# Vitraya Studio

Aplicativo local de operação de ofertas de afiliados, separado da Nexakeep.
Leia docs/CONTINUIDADE.md e docs/execucao antes de trabalhar. Preserve os dados.
Cada agente registra seu próprio checkpoint após marcos e testes reais.
Nunca grave credenciais, arquivos importados, dados reais nem banco em commits.
Não envie mensagens reais em testes. Integrações só aparecem conectadas após teste real.
Servidor restrito a 127.0.0.1. API local não é uma implantação multiusuário.
